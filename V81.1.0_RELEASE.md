# OFFSCRPT V81.1.0
## Navigation, Branding & Intelligence Unification

Base: OFFSCRPT V81.0.0 Universal Knowledge Engine

### User-facing changes
- Blog → SCRPTS
- Knowledge + primary Ask AI entry → ASK OFFSCRPT
- Primary header reduced to Home / SCRPTS / Community / Explore
- Secondary systems remain available through Menu, Command Palette, profile/contextual access

### Compatibility
- Existing `/#blog` hash route remains supported.
- Existing Firestore and API identifiers using `blog` remain intentionally unchanged.
- Existing Site-wide AI Copilot remains available as a secondary utility.
- Existing V77–V81 functionality is preserved.
