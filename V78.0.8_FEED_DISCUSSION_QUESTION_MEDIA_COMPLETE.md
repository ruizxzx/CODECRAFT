# OFFSCRPT V78.0.8 — Feed / Discussion / Question Media Complete

- Added shared `FeedMediaPreview` for consistent fixed-height media rendering across feed surfaces.
- Added compact media previews to Social Hub discussions, questions, community posts and Home Community Highlights.
- Questions now expose `mediaUrls`, `coverImage`, and `coverImageAlt` while retaining legacy `attachments`.
- Question creation/edit persists media consistently.
- Root discussion media URLs are persisted by the legacy composer.
- Media URLs are deduplicated and limited to eight per question.
- Multi-media previews use a controlled two-column layout.
- Feed/detail media remains constrained and uses `object-cover`.
