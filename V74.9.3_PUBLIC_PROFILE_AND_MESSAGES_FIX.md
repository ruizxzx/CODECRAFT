# OFFSCRPT V74.9.3 — Public Profile + Messages Repair

## Fixed

- Viewing another profile while signed in no longer subscribes to `users/{uid}`. Only the owner can use the private user document; everyone else uses `publicProfiles/{handle}`.
- Public profile lookup remains available to logged-out and logged-in visitors through the public projection.
- People discovery now reads public profile projections and joins each claimed handle to its public `usernames/{handle}` UID reservation, restoring message targets without exposing private `users/{uid}` documents.
- Unclaimed users remain hidden from the public people directory.

## Required Firebase deployment

The repository contains the correct Firestore rules (`src/firestore.rules`), including public reads for `publicProfiles` and `usernames`. A Vercel deployment does **not** deploy Firestore rules. The live Firebase project must deploy this rules file to `krishficient-portfolio` before testing public profiles.

Recommended command from an authenticated Firebase CLI environment:

```bash
firebase deploy --only firestore:rules --project krishficient-portfolio
```

After rules deployment, redeploy the Vercel app so the new client bundle is live.
