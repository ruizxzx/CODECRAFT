# OFFSCRPT V76.0.1 — Home Runtime Fix

## Fix
Resolved a JavaScript temporal-dead-zone runtime crash in `PersonalizedHomeSections.tsx`.
`secondarySections` and `trendingItems` referenced `displayedArticles` before its declaration, causing the production error `Cannot access 'Ce' before initialization` after Vite minification.

The declarations are now ordered so all derived values are initialized before any `useMemo` callback consumes them.

No feed features were removed. The existing V76 feed/discovery, recommendation, Firestore quota optimization, R2 media upload, and crop/preview functionality are retained.
