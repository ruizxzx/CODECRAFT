# V79.2.3 — OpenRouter AI Cache Migration

Fixes existing-browser persistence of pre-OpenRouter Gemini AI results.

The old client cache used `offscrpt:ai:v2:*`, so a browser that had already generated a Gemini summary could satisfy the same request from localStorage without contacting the new OpenRouter gateway. V79.2.3 uses an OpenRouter-specific cache namespace and removes legacy AI result keys on module initialization. AI notes are preserved.
