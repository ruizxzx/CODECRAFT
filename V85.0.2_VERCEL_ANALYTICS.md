# OFFSCRPT V85.0.2 — Vercel Web Analytics

## Implemented
- Added `@vercel/analytics` 2.0.1.
- Mounted the React `<Analytics />` component once at the application root.
- Preserved existing Firestore/application analytics.
- No user-identifying Firestore data is sent to Vercel by this integration.

## Deployment
1. In Vercel Project → Analytics, click **Enable** if Web Analytics is not enabled yet.
2. Deploy this build to Vercel.
3. Visit the production site and verify analytics requests in the browser Network tab and data in the Vercel Analytics dashboard.

## Notes
- Vercel Web Analytics is intended for production traffic and the package does not track development mode.
- This integration does not replace OFFSCRPT's existing application analytics.
- OFFSCRPT currently uses hash-based SPA navigation; Vercel's standard page-view integration is installed globally without changing routing behavior.
