# OFFSCRPT V88.0.1 — Vercel Deployment Fix

Patch release for V88.0.0.

## Fixes
- Removed shared/server helper modules from `/api` so they are not discovered as additional Vercel Serverless Functions on the Hobby plan. Shared server code now lives under `/server`.
- Removed the unavailable `@vercel/node` type dependency by using a minimal local Vercel request/response type contract.
- Fixed `getIntelligenceFlags` typing in the OFFSCRPT retrieval helper.
- Fixed the R2 presigned URL expiry reference (`input.expiresIn`).

## Compatibility
- Canonical `/api` route handlers remain unchanged in purpose.
- Existing V86/V87 commerce/storefront behavior is preserved.
- Digital product private R2 storage remains server-only.

## Deployment
The repository now exposes only route handlers under `/api`; shared server utilities are outside `/api`, preventing them from consuming the Hobby Serverless Function allowance.
