# OFFSCRPT V86.0.2 — Commerce Firestore Hardening

## Fixes

- Firestore REST Commit now uses valid `projects/.../databases/(default)/documents/...` document resource names.
- Firestore Commit has no unsupported `create` write operation; new-document writes are represented as `update` writes with `currentDocument.exists = false`.
- Partial update writes now include `updateMask.fieldPaths`, preventing payment/order/entitlement/revenue documents from being accidentally replaced by partial documents.
- Creator product/price creation, checkout order/payment creation, test payment confirmation, and test refunds all use the corrected commit format.
- Commerce customer product/order/entitlement listing avoids unnecessary composite-orderBy dependencies in the current foundation UI and sorts bounded results client-side.
- Master Control Commerce diagnostics use a server-authoritative diagnostics endpoint instead of unauthorized client-side collection-wide aggregate reads.

## Deployment

Deploy the application plus the repository-root `firestore.rules` and `firestore.indexes.json` to the OFFSCRPT Firebase project.

Required Vercel Production variables remain server-only:

- GOOGLE_CLOUD_PROJECT
- GOOGLE_SERVICE_ACCOUNT_CLIENT_EMAIL
- GOOGLE_SERVICE_ACCOUNT_PRIVATE_KEY
- CRON_SECRET
