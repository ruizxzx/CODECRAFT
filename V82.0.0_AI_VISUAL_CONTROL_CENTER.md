# OFFSCRPT V82.0.0 — AI Visual Control Center

Adds centralized, Master Admin-controlled AI appearance settings using the existing `siteConfig/global` configuration architecture.

## Implemented
- 19 validated AI color tokens with safe defaults.
- Realtime site-wide AI theme propagation without frontend rebuild.
- Master Control → Intelligence → AI Control · Appearance panel.
- Color picker + HEX input for every token.
- Live preview.
- Reset defaults.
- Server-side Firestore validation for AI theme values and Master Admin-only writes.
- AI-themed wrappers for OFFSCRPT AI, AI content assistant, AI Writer, Knowledge and Learn surfaces.
- Header OFFSCRPT AI action now consumes the centralized AI primary color.

## Compatibility
Existing routes, content schema, OpenRouter gateway, AI features and site configuration are preserved. The existing Firestore `siteConfig/global` document is extended only with the optional `aiTheme` map.

## Validation limitation
A full dependency-backed TypeScript/Vite build must be run in an environment with the project's dependencies installed. Parser/static validation should be reported separately from a successful production build.
