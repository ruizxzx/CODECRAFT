# OFFSCRPT V87.0.0 — Creator Storefront

## Purpose
V87 turns the working V86 Commerce Foundation into a public creator storefront layer without introducing a second commerce or entitlement system.

## Added
- Public creator Store tab
- Public product detail route `#product/{productId}`
- Public active-product discovery on creator pages
- Creator Studio product visibility control (public/private)
- Creator Studio public product preview link
- User purchase state on product pages
- Server-authoritative test purchase flow reuse
- Purchase entitlement resolution scoped to resource type/id
- Basic creator orders/purchases compatibility with V86

## Security
- Public storefront reads are limited to active/public products and active prices by Firestore rules.
- Product creation/status/visibility changes remain server-authoritative.
- Product pages never expose private products.
- Customer access is resolved through the V86 entitlement engine.

## Scope boundary
V87 does not implement live payment providers, subscriptions, full digital-file delivery, courses, bundles, affiliate payouts, or the Creator Marketplace. Those remain later builds.

## Public listing
Creator storefront product listing uses a server-side public Commerce API so public users never need permission to query private creator product records and no storefront query depends on an undeployed composite index.
