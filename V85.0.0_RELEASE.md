# OFFSCRPT V85.0.0 — DISCOVERY CORE

V85 builds the shared discovery foundation on top of V84.

## What changed

### Universal Search 2.0 foundation
The existing unified search now supports a structured query plan without changing existing call sites. Users can combine normal text with inline filters:

- `type:article`
- `topic:travel`
- `tag:cinema`
- `author:krishsarkar` / `from:krishsarkar`
- `community:...`
- `series:...`
- `after:2026-01-01`
- `before:2026-12-31`

Ranking combines lexical relevance, title relevance, topic/tag matches, freshness and engagement while continuing to run authorization filtering before returning results.

### Shared Discovery Core
`src/lib/discovery.ts` now owns reusable discovery primitives so Search, Explore and recommendations can evolve from the same scoring vocabulary instead of separate algorithms.

### Recommendation engine upgrade
The existing RecommendationEngine now uses shared freshness, engagement, quality, novelty and diversification logic. Existing recommendation APIs and the personalized feed remain compatible.

### Search UX
The existing SearchModal now understands the V85 query syntax, shows recent local searches, and displays ranked results from the unified discovery ordering.

## Compatibility
- V84 Knowledge Engine retained.
- Existing Firestore schema retained.
- No new Firestore collection or security-rule migration required by V85.
- Existing routes and content IDs retained.
- Existing permission model retained.
