# OFFSCRPT V74.9 — Public Profile + Handle UX Fix

- Public profile lookup uses `publicProfiles/{handle}` so logged-out visitors can open claimed profiles.
- Private `users/{uid}` is no longer a public read surface.
- Public profile projection excludes email, UID, moderation state, and admin/security fields.
- New handle claims and handle changes create/sync the public profile projection and remove stale old-handle projections.
- App prompts for an unclaimed handle only once per auth session and never reopens after a successful claim.
- Community profile edits propagate back to the root app auth profile state so the claim modal/header cannot remain stale.
- People discovery reads public profile projections and hides unclaimed users.
