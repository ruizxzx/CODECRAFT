# OFFSCRPT V86.0.3 — Commerce Admin Authentication Fix

## Fix
The Commerce Diagnostics API now uses the same master-admin bootstrap authorization as the existing OFFSCRPT Master Control UI. Verified bootstrap admin emails, configured master-admin UID records, and configured master-admin email records are accepted.

The endpoint now returns HTTP 403 when an authenticated user is not authorized, instead of conflating authorization failure with a generic bad request.

## Compatibility
No changes to Commerce financial mutation authorization, product creation, test purchases, refunds, entitlement logic, community systems, or existing Master Control behavior.
