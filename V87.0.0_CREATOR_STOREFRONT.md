# OFFSCRPT V87.0.0 — Creator Storefront

## Architecture
Creator Profile → Public Store → Product → V86 Commerce Price → Checkout → Entitlement → Access

## Firestore
No separate storefront database is introduced. V87 reads the canonical V86 `commerceProducts` and `commercePrices` collections. Financial mutations continue through `/api/commerce`.

## Product visibility
A product appears publicly only when both are true:
- `status == active`
- `visibility == public`

Private/draft/archived/disabled products remain unavailable to public storefront readers.

## Product route
`/#product/{productId}`

## Creator page
Existing `#creator/{username}` gains a Store tab. Existing creator content tabs remain unchanged.

## Test purchasing
V87 reuses V86 test-mode checkout and entitlement creation. No real money is charged when `COMMERCE_PAYMENT_MODE=test`.

## Important deployment note
Firestore rules and indexes must be deployed separately to the production Firebase project.
