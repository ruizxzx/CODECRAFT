# OFFSCRPT V79.0.0 — AI Reading & Learning

V79 introduces a centralized Gemini-powered AI layer for reading, comprehension, content analysis and learning. The existing V78 Discussion Intelligence endpoint remains for backward compatibility while the active discussion summary path now uses the central AI gateway.

## Included
- Central AI Gateway with Firebase ID-token verification.
- Task-aware Gemini model routing (fast / balanced / deep configuration).
- Grounded structured JSON responses with prompt/version metadata.
- Client-side result cache keyed by task, content identity, revision and options.
- Server-side in-memory response cache and per-user daily request guard.
- Configurable context, cache TTL and daily request limits.
- Article AI Reading Assistant: summarize, explain, ask AI, key concepts, intelligence, tags, prerequisites, learning, questions, flashcards, quality and creator assistance.
- Summary modes: TL;DR, quick, standard, deep, expert.
- Reading modes: beginner, study, revision and deep-dive controls.
- Selection-aware source context for inline explanations.
- Article intelligence schema covering arguments, claims, examples, terminology, entities, topics, difficulty, prerequisites, open questions and related concepts.
- Discussion intelligence via the same gateway: overview, arguments, agreements, disagreements, unresolved and useful-reply signals.
- Question and answer content can be analyzed through the same AI surface.
- Community post and series AI assistant surfaces.
- AI-generated question/quiz and flashcard generation.
- Learning history capture and /#learn dashboard with AI recaps.
- Compare and synthesize UI foundation using a second pasted source.
- AI notes with safe local fallback storage.
- Semantic extraction, related-content and creator-assistant task endpoints ready for later V79.x UI expansion.
- Core OFFSCRPT publishing, reading, discussion and Q&A flows remain independent of Gemini availability.

## Planned V79.x extensions already supported by the gateway contract
- Cross-content synthesis.
- Knowledge extraction.
- Prerequisite detection.
- Adaptive learning.
- Creator AI transformations.
- Semantic search/recommendation signals.
- AI analytics and cost controls.
- Knowledge-page generation and Article/Question/Discussion → Knowledge workflows.

## Security and reliability rules
- Never trust client-supplied admin state for AI access.
- Verify Firebase ID tokens server-side before calling Gemini.
- Do not silently modify published metadata from AI suggestions.
- Do not make AI the sole authority for factual correctness or moderation enforcement.
- Preserve source content, author attribution and visibility boundaries.
- AI failures must remain recoverable and must not break the underlying content page.
