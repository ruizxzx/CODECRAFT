# V78.0.7 — Feed / Discussion / Question Media Layout

## Fixed
- Added a shared fixed-frame media renderer for feed/discovery cards so uploaded images stay inside stable card dimensions.
- Added media previews to the Social Hub Everything Feed for root posts, community posts and questions.
- Added compact fixed media previews to the Discussions tab.
- Added compact fixed media previews to the Questions tab, including legacy `attachments`, `mediaUrls` and `coverImage` fields.
- Added optional image URL support to new questions so newly created questions can populate the same media renderer.
- Added media previews to Home community highlights and the main Community feed.
- Prevented the Community feed from rendering the same post media once through the shared preview and again through `CommunityPostExtras`.
- Updated compact `CommunityPostExtras` media behavior to use a fixed-height frame rather than intrinsic image height.
- Expanded question Firestore update allowlist to include media fields used by the question UI.
- Added required `moderationState` / `isAnonymous` fields to question creation so the client matches the hardened question rules.
