# OFFSCRPT V85.1.0 — Vault + Communities + Creator Workspace

## Scope
Completes and connects Vault collections/citations/highlights, community membership controls/wiki/FAQ/resources, and creator scheduling/collaboration/review workflows.

## Implemented
- Unified Vault collections for saved articles, highlights and notes via references.
- Private Vault search/organization helpers.
- Source references and citation generation.
- Inline article highlight rendering anchored by article block IDs with safe quote fallback.
- Public/private/invite-only/approval-required community membership modes.
- Join requests and community invitations.
- Community wiki, FAQ and resources.
- Community-scoped bounded analytics.
- Creator scheduling metadata and workflow state.
- Vercel cron-compatible server schedule processor using server-only service-account credentials.
- Creator collaborator invitations and roles.
- Review workflow states and conflict-aware helper checks.
- Master/Discovery/Knowledge compatibility considerations.

## Security
- Vault data remains user-owned.
- Community reads are mode-aware for direct community documents and posts.
- Collaboration/scheduling permissions are enforced server/rule-side where supported by existing architecture.
- Scheduled content is not intended to become discoverable before publication.

## Data/Firestore
New scoped collections/subcollections include Vault collection item references, community join requests/invitations/wiki/faq/resources, article workflow schedule documents, and collaborator invitations. Existing canonical content IDs are preserved.

## Scheduling configuration
Set server-only environment variables: GOOGLE_CLOUD_PROJECT, GOOGLE_SERVICE_ACCOUNT_CLIENT_EMAIL, GOOGLE_SERVICE_ACCOUNT_PRIVATE_KEY, CRON_SECRET. Enable Vercel Cron through the included vercel.json.

## Validation
Source-tree TypeScript/TSX parse validation: PASS. Dependency-backed typecheck/production build may remain blocked when dependencies are unavailable in the build environment.

## Known limitations
- Full browser validation requires a running deployment/authenticated test accounts.
- Community analytics are bounded to avoid unbounded platform scans.
- Highlight anchoring can become unavailable after major source edits; the implementation avoids silently placing highlights on incorrect text.
