# OFFSCRPT V74.9.1 — Public Profile Route Repair

- Public handle routes now recover the signed-in owner/admin from the private profile when a public projection is missing.
- Master admin login performs a cloud backfill of all claimed handles into `publicProfiles/{handle}` so existing accounts become publicly routable without exposing UID/email.
- New/updated profiles continue to mirror to `publicProfiles`.
- Removed the duplicate Unique @Handle editor field.
- Public profile projections remain UID/email-free.
- Existing ownership and interactions remain UID-based.
