# OFFSCRPT V79.2.1 — OpenRouter Runtime + Firestore Hardening

- Fixed Vercel ESM deployment resolution by shipping the OpenRouter provider as `api/ai/openrouter.js` and importing it explicitly as `./openrouter.js`.
- Added graceful structured-output fallback for free OpenRouter models that reject JSON mode.
- Added tolerant JSON extraction for fenced/model-wrapped JSON responses.
- Cache hits no longer consume the daily AI quota.
- Added collection-group indexes for `posts.authorId`, `answers.authorId`, and `following.uid`.
- Added collection-group read rules required by the existing public/identity synchronization queries.
- Added root and authenticated community post view-receipt permissions so view tracking no longer generates avoidable 403 errors.
- Replaced the stale external PWA/favicon fallback with a local OFFSCRPT icon so an expired Postimg certificate cannot break manifest loading.
- Existing OpenRouter AI, Firebase authentication, caching, retry/fallback routing and Gemini-free V79 architecture remain intact.
