# OFFSCRPT V81.0.0 — Universal Knowledge Engine

V81 extends the V80 Intelligence Core with a user-facing universal knowledge layer. It preserves existing Search, Explore, Saved, AI Copilot, Topics, Series, Discussions and Questions functionality and adds additive routes for Knowledge, Vault and Research.

## Implemented
- OFFSCRPT Knowledge workspace (`#knowledge`) with grounded Ask, search, source navigation, reading-signal summary and personalized path.
- OFFSCRPT Research workspace (`#research`) using permission-checked OFFSCRPT retrieval followed by grounded multi-source synthesis.
- Personal Vault workspace (`#vault`) linked to existing cloud saves/collections, plus local private notes.
- Command Palette entries for Ask OFFSCRPT, My Vault and OFFSCRPT Research.
- Shared knowledge-engine helpers for content normalization, hybrid search and personalized path ranking.
- AI client helper for the existing server-side retrieval endpoint. OpenRouter remains behind the existing backend gateway.
- No private-source exposure is introduced by the client; retrieval continues to use the existing server-side Firebase-token and Firestore authorization path.

## Foundation-only / not falsely claimed as complete
- No external vector database or durable embedding worker is introduced. Semantic retrieval remains an extensible hybrid foundation over the existing OFFSCRPT retrieval layer.
- Local Vault notes are intentionally device-local; existing saved items and collections remain cloud-synced through their established Firestore paths.
- Full analytics warehouse, durable recommendation training pipeline and background re-indexing workers remain future infrastructure work.
