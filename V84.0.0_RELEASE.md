# OFFSCRPT V84.0.0 Release

Production Knowledge Engine architecture is established around one canonical content-to-retrieval pipeline.

### User-visible
- Knowledge view reports the current OFFSCRPT source inventory and V84 manifest.
- Existing OFFSCRPT AI/Research/Source flows receive richer retrieval metadata.

### Infrastructure
- Semantic chunking now respects heading boundaries and deterministic versions.
- Embedding and vector provider interfaces are vendor-neutral.
- Optional server-side provider adapter supports embedding, vector query, upsert and delete.
- Permission-filtered retrieval remains mandatory before AI context construction.

### Known limitations
A real vector/search backend must be supplied through deployment environment variables; this archive does not invent or embed third-party service credentials. A durable worker is not provisioned here.

### Optional semantic provider environment
- `OFFSCRPT_EMBEDDING_ENDPOINT`
- `OFFSCRPT_EMBEDDING_API_KEY`
- `OFFSCRPT_EMBEDDING_MODEL`
- `OFFSCRPT_VECTOR_ENDPOINT`
- `OFFSCRPT_VECTOR_API_KEY`
- `OFFSCRPT_KNOWLEDGE_WORKER_SECRET`

These are server-only deployment settings. Without them, OFFSCRPT remains on its existing Firestore-backed lexical retrieval fallback.
