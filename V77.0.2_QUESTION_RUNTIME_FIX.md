# V77.0.2 — Question Runtime Fix

Fixed a production React Hooks ordering bug in the dedicated QuestionView.

## Root cause
`childrenByParent` was calculated with `useMemo` after loading/not-found/removed early returns. The first render could return before the hook, while the loaded render invoked it, causing React error #310 (`Rendered more hooks than during the previous render`).

## Fix
All hooks in QuestionView now execute unconditionally before render-state early returns.

## Navigation
Question cards in Home discovery and Social now open the dedicated `/#question/{id}` route.

## Backward compatibility
Existing V77 Q&A, media uploads, voting, follows, moderation, Firestore sync, R2 uploads, and feed features are retained.
