# OFFSCRPT V74.7 — Global Handle Propagation

This release makes a username change a platform-wide identity update while keeping Firebase UID as the stable relationship key.

Updated denormalized identity snapshots include root posts, community posts, root/article/community comments, questions, answers, owned communities, community memberships, following references, creator topics, owned series, sent messages, notifications generated by the user, reports authored by the user, admin notifications authored by the user, site-moderator metadata, and owned article author metadata.

The propagation runs from `updateCommunityProfile()` after the canonical profile/handle transaction succeeds. Writes are scoped by the immutable UID and committed in Firestore batches.

Firestore Rules allow only identity-field changes for the matching owner. Users cannot use this path to alter content, roles, moderation state, or another user's data.

Existing interactions remain linked by UID and are not recreated or detached when the handle changes.
