OFFSCRPT V85.1.1 — DEPLOYMENT FIX

Root cause:
V85.1.0 declared Vercel Cron schedule * * * * *, which is rejected on Vercel Hobby.
Vercel's current documentation indicates Hobby supports once-per-day precision, while Pro/Enterprise support once-per-minute scheduling.

Fix:
- Removed native crons from vercel.json.
- Added GitHub Actions scheduler every 5 minutes.
- Added manual workflow_dispatch.
- Cron endpoint requires CRON_SECRET.
- Added scheduling setup documentation.
- Version/release notes updated.
