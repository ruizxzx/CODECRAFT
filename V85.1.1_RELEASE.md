# OFFSCRPT V85.1.1 — Scheduling Deployment Fix

## Problem
V85.1.0 registered a Vercel Cron schedule of `* * * * *`. On Vercel Hobby, frequent native Cron schedules are not permitted, so the deployment was rejected during configuration validation.

## Fix
- Removed native Vercel Cron configuration from `vercel.json`.
- Added a GitHub Actions scheduler running every 5 minutes.
- Reused the existing `/api/cron/process-schedules` endpoint.
- Added mandatory `CRON_SECRET` authentication.
- Added optional `OFFSCRPT_PRODUCTION_URL` GitHub repository variable.
- Added manual workflow dispatch.
- Documented setup and timing behavior.

## Compatibility
No content, Vault, Community, Creator Studio, Search, Discovery, Knowledge Engine, or Vercel Analytics functionality was removed.

## Configuration
Vercel:
- `CRON_SECRET`
- `GOOGLE_CLOUD_PROJECT`
- `GOOGLE_SERVICE_ACCOUNT_CLIENT_EMAIL`
- `GOOGLE_SERVICE_ACCOUNT_PRIVATE_KEY`

GitHub:
- repository secret `CRON_SECRET`
- optional repository variable `OFFSCRPT_PRODUCTION_URL`
