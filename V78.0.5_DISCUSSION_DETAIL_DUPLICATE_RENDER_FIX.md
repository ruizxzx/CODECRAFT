# V78.0.5 — Discussion Detail Duplicate Render Fix

## Root cause
`CommunityPostView` intentionally renders the primary post media and poll. It then calls `CommunityPostExtras` with `showMedia={false}` and `showPoll={false}` so the extras component should only render hashtags. `CommunityPostExtras` accepted those props but ignored them, unconditionally rendering `PostMediaPreview` and `PollBlock`. This caused the same media and poll to appear twice on discussion detail pages.

## Fix
- `CommunityPostExtras` now honors `showMedia` and `showPoll`.
- The `compact` prop is passed through to the poll renderer.
- Discussion detail continues to render the full media gallery and full poll exactly once.
- Community feed, explore, social hub, and profile cards keep their existing compact media/poll rendering.

## Expected behavior
One post media block + one poll block on the discussion detail page, with hashtags rendered below.
