# OFFSCRPT V75.3 — Interaction Feedback, Changelog, Problem Reports, Announcements

## Added
- Neo-brutalist red filled-heart feedback for comment likes.
- Repost/save buttons retain stronger active-state feedback.
- Public `/changelog` page with recent release history.
- Firestore-backed `siteProblemReports` for user bug reports.
- Master Admin Reports → Site Problem Reports queue with status and response controls.
- Cloud-backed dismissible popup announcements controlled from Master Admin → Site Control.
- Announcement targeting: all, home, blog, article, community, explore, series, creator, changelog.
- Changelog added to the public footer.

## Cloud model
- Problem reports are written to `siteProblemReports/{reportId}`.
- Admin status updates and responses are persisted to Firestore.
- Announcement configuration is persisted through `siteConfig/global`, which is already realtime subscribed site-wide.
- Announcement dismissals are client-local and keyed by announcement ID so an admin can publish a new announcement without inheriting an old dismissal.
