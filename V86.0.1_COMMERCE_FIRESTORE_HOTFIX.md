# V86.0.1 Commerce Firestore Hotfix

The Commerce API uses the Firestore REST `documents:commit` endpoint. `fsGet`/`fsPatch` endpoints correctly use full REST URLs, but the Commit API requires each Write document name to be a Firestore resource name such as:

projects/krishficient-portfolio/databases/(default)/documents/commerceProducts/<id>

The previous V86.0.0 implementation passed:

https://firestore.googleapis.com/v1/projects/krishficient-portfolio/databases/(default)/documents/commerceProducts/<id>

inside `Write.create/update.name`, producing HTTP 400 INVALID_ARGUMENT.

V86.0.1 normalizes commit write names before sending them.
