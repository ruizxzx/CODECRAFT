# OFFSCRPT V89.0.0 RELEASE

## Marketplace + Buyer Experience

V89 introduces the public digital-product marketplace layer on top of the existing V86–V88 commerce and digital-product architecture.

### Included
- Shop / Marketplace discovery route and navigation
- Featured, trending, newest releases, and popular creators
- Product search with debounce, URL state, normalization, pagination, filters, and sorting
- Category discovery
- Reusable marketplace product cards with previews, price, Save, and Owned state
- Saved Products buyer library
- Product-detail gallery with fullscreen viewer and keyboard controls
- Product breadcrumbs, share/copy-link, creator, related, and more-from-creator sections
- Buyer authentication gating for private actions
- Canonical entitlement-based ownership state
- Marketplace analytics events and product-card impressions
- Safe public product projection through the existing commerce API
- Firestore saved-product rules and marketplace indexes
- Marketplace-specific runtime error boundary
- V88.7 R2 purchase/download architecture preserved

### Deliberately deferred
- Live payment provider and webhooks (V90)
- Advanced orders/delivery/invoices (V91)
- Vendor onboarding/seller dashboard (V92)
- Commission engine (V93)
- Balances/payouts (V94)
- Admin finance (V95)
- Reviews/moderation/trust (V96)
- Coupons/affiliates/growth/final launch hardening (V97)

### Deployment
V89 preserves the nine existing `/api` route candidates to remain within the Vercel Hobby constraint. Shared server utilities remain under `server/`, not `api/lib/`.

### Required deployment configuration
No new R2 environment variables are required for marketplace browsing. Existing V88 public-media and dedicated private-product R2 variables remain unchanged.

### Validation honesty
The repository includes static marketplace checks and all existing structural checks. A complete dependency-based production `npm run build` may be blocked in the build environment when dependency installation is interrupted; such a status must be reported as BLOCKED rather than PASS. No live Firebase/R2/Vercel integration is claimed unless actually executed.
