# V77.0.1 — Vercel Build Fix

## Problem
Vercel failed during `vite build` because `src/lib/social.ts` exported `getQuestionForModeration` twice.

## Fix
The duplicate legacy export was removed. The canonical Q&A moderation helper remains in the Q&A section and retains its `questionPublic(...)` mapping.

## Compatibility
No Q&A features, R2 media uploads, Firestore paths, rules, feed/discovery functionality, comments, communities, profiles, or admin features were removed by this fix.
