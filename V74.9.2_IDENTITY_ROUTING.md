# OFFSCRPT V74.9.2 — Identity / Public Profile Routing Repair

- New accounts receive a temporary random display name such as `Builder 4821` and no claimed @handle.
- Public `/#@handle` routes resolve from the public profile directory without requiring authentication.
- Signed-in owners can self-repair a missing public profile projection from `users/{uid}`.
- The owner's canonical profile state is preferred immediately after a handle change, avoiding a transient `USER NOT FOUND` state.
- Public profile rendering works without exposing the internal Firebase UID in the public projection.
- Root/community posts on public profile pages can resolve by public handle even when the viewer is signed out.
- Handle claim UI is never prefilled with an administrator-specific handle.
- Handle changes create a public legacy alias so old profile links can redirect to the new handle.
- Master Admin can change a user's handle through the Users control path; the canonical UID remains unchanged.
- `VERSION.md` remains the build version source.
