# V79.2.0 — OpenRouter AI Migration

- Replaced Gemini transport with OpenRouter server-side API.
- Default model is `openrouter/free` (OpenRouter's free-model router).
- Preserved the V79 AI task schema and UI.
- Added provider fallback routing, retry/backoff, structured JSON responses, caching, authentication and daily request guards.
- Discussion Intelligence now uses the same OpenRouter provider.
- Removed the unused `@google/genai` dependency.
- AI failures remain isolated from core OFFSCRPT content.

## Deployment
Set `OPENROUTER_API_KEY` in Vercel. Keep it server-side. Optional routing variables are documented in `.env.example`.


OpenRouter documents an OpenAI-compatible Chat Completions API and a free router that selects from available free models; current free-plan documentation lists a 50 requests/day rate limit.
