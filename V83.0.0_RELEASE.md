# OFFSCRPT V83.0.0 — MOBILE RESPONSIVENESS

## Focus
Site-wide mobile UI hardening. Desktop layout is preserved; phone layouts are allowed to reflow, stack, wrap and locally scroll where needed.

## Root cause addressed
The previous mobile quick dock contained six actions while each action was sized at 20%, producing a 120% total row width before gaps/padding. This could push the last action outside the viewport. V83 changes it to five flexible equal-width actions and moves Saved back into the existing menu/drawer.

## Implemented
- Five-action mobile quick dock: Home, Search, AI, Post, Menu.
- Saved remains fully accessible through the existing navigation drawer.
- Site-wide mobile overflow containment.
- Mobile-safe sizing for controls and media.
- Long text/URLs/code handling.
- Phone-width stacking for common multi-column grids.
- Fixed overlay/dialog width protection.
- Article utility toolbar wraps on phones.
- Article metadata/breadcrumbs wrap safely.
- Wide analytics tables remain horizontally scrollable inside their existing containers instead of widening the page.
- Existing desktop navigation and functionality preserved.

## No database changes
V83.0.0 does not change Firestore rules, indexes, or Firebase configuration.
