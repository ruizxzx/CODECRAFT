# OFFSCRPT V84.0.0 — Production Knowledge Engine

## Implemented
- Canonical V84 chunking and deterministic chunk identity.
- EmbeddingProvider and VectorIndexProvider abstractions.
- Hybrid retrieval weighting seam with quality/freshness metadata.
- Generic server-side embedding/vector adapter driven by deployment environment variables.
- Permission-preserving OFFSCRPT retrieval with enriched source metadata and routes.
- Knowledge Engine manifest/inventory for current canonical content.
- Master Control Knowledge Engine readiness/inventory panel.
- Admin-only provider health endpoint.
- V84 regression/static validation script.

## Foundation / deployment-dependent
- A real external vector database/search service is not included in the ZIP. Configure the provider endpoints/secrets in the deployment environment to enable live semantic vectors.
- A durable background worker/queue is not provisioned by this frontend repository; existing indexSync remains compatible for future workers.
- Firestore remains canonical and is not used as the vector database.

## Security
- Existing server-side retrieval permission checks remain the gate before AI context.
- Provider endpoints are server-only.
- No embedding/vector secrets are written to Firestore.
