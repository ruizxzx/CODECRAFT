# OFFSCRPT V83.0.0 — Mobile Responsiveness

## Objective
Harden the existing OFFSCRPT UI for phone-sized viewports without changing desktop behavior or removing functionality.

## Implemented
- Reworked the mobile quick-navigation dock from six fixed 20%-width actions to five equal flexible actions so it cannot exceed the viewport.
- Kept Saved accessible through the existing navigation drawer rather than sacrificing a dock slot.
- Added site-wide mobile overflow containment and safe sizing for media, inputs, buttons, long text, code blocks and tables.
- Stacked common multi-column grids on phone widths while preserving their desktop/tablet layouts.
- Hardened fixed dialog/popover sizing against narrow viewports.
- Made Article reading utility controls wrap on phones instead of running off-screen.
- Made article metadata/breadcrumb content wrap safely.
- Preserved intentional horizontal scrolling for wide analytics/data tables inside their existing containers.

## Compatibility
- No Firestore schema/rules/index changes.
- No route changes.
- No authentication or AI behavior changes.
- Existing desktop header/navigation remains unchanged.

## Validation
Static syntax/import/export and project regression checks should be run against the packaged source. A browser/device matrix should additionally be run in the deployment environment because this source package does not include a browser runtime.
