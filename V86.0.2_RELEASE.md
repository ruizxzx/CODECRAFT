# OFFSCRPT V86.0.2 RELEASE

Commerce Firestore hardening release.

### Fixed

1. REST Commit document resource names.
2. Unsupported Firestore `create` write payloads.
3. Partial update data loss risk by adding Commit update masks.
4. Client-side commerce list queries that could require undeployed composite indexes.
5. Commerce Admin aggregate reads that were blocked by Firestore rules.

### Preserved

All V85.1.2 functionality and V86.0.0/V86.0.1 commerce architecture.

### Limitations

Live Firebase deployment/index readiness and payment-provider production tests must be verified after deployment.
