# OFFSCRPT V88.0.6 — Purchases + Secure Digital Downloads

## Added
- My Purchases account page at `#purchases` / `#my-purchases`.
- Purchases shortcut inside the My OFFSCRPT dashboard.
- Purchases shortcut inside the authenticated navigation drawer.
- Server-authoritative purchase listing using canonical `entitlements`, `commerceOrders`, `commerceProducts`, and `digitalProductVersions`.
- Secure download endpoint that requires an authenticated Firebase account with an active product entitlement.
- Short-lived R2 GET presigned URLs (5 minutes) for purchased files.
- Download filenames encoded through the signed R2 response-content-disposition override.
- Purchase cards show product imagery, creator, purchase date, order amount, entitlement status, and current downloadable files.
- Refunded/expired/revoked purchases remain visible in history but do not receive download links.
- Product file storage key validation was tightened so upload completion must use the exact server-derived storage key.

## Security
- Download access is never granted from client-side product visibility.
- The browser cannot read `digitalProductFiles` directly; the server verifies the entitlement before signing a GET URL.
- Existing public-media R2 credentials remain separate from product R2 credentials.

## Navigation
- `#purchases`
- `#my-purchases`

## Compatibility
- Existing commerce orders, entitlements, creator storefronts, and V88 digital product creation/upload flows remain on their canonical collections.
