# OFFSCRPT V75.1 — Message People Identity Fix

## Fix
Legacy message participant metadata no longer overrides richer current public profile identity. Blank legacy participants are not rendered as fake `User` / `@` contacts.

## Source of truth
Current public profile identity wins; legacy message sender/recipient metadata is fallback-only. Existing relationships remain keyed by UID.

## Verification
`npm run check:message-identity` validates the merge and blank-identity guards.
