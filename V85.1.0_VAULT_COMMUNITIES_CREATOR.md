# V85.1.0 Architecture Notes

## Personal knowledge
Vault extends the existing saved-content model rather than creating a second collection system. Highlights and notes can be associated with user collections and retain source references for citation/navigation.

## Community
Membership mode is represented explicitly and join state is represented separately from membership. Wiki, FAQ and resource records are scoped to a community and guarded by community roles.

## Creator workspace
Scheduling is stored separately in an article workflow document. Publication state fields on the canonical article are used for discovery visibility. Collaborators remain associated with the canonical article document, with invitation state stored in a dedicated collection.

## Integration
Vault → Citation → Composer and Community → Question → Answer and Creator → Review → Schedule → Publish are intended to share canonical content IDs.
