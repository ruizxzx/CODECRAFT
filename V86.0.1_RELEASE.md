# OFFSCRPT V86.0.1 — Commerce Firestore Commit Fix

Hotfix for V86.0.0 Commerce Foundation.

## Fixed
- Firestore REST commit writes now use canonical document resource names (`projects/.../databases/(default)/documents/...`) instead of full REST URLs in Write.document.name.
- Product creation now uses Firestore `create` for the new product document.
- Initial price creation now uses Firestore `create` for the new price document.
- Additional price creation now uses Firestore `create` for the new price document.
- Existing product updates remain `update` operations.

## Root cause
V86.0.0 constructed Firestore commit payloads with the full HTTPS REST URL as the document `name`. Firestore Commit expects a resource name beginning with `projects/`, so product creation returned INVALID_ARGUMENT with "lacks projects at index 0".

## Validation
Static validation and source audits are included in BUILD_VALIDATION_V86.0.1.txt. Live Firebase and dependency-backed build checks must still be performed in the deployment environment.
