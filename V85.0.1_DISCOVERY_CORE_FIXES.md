# OFFSCRPT V85.0.1 — Discovery Core Fixes

## Purpose
Focused corrective release for V85 Discovery Core. No unrelated features are added.

## Fixed
- Parsed search filters now flow into the shared search engine.
- Supports `type: article`, quoted filter values, bare `@handle`, and bare `#topic`.
- Author filtering resolves against both public username/handle and stable UID.
- Search result click telemetry is wired to actionable result navigation.
- Questions are loaded once per SearchModal session rather than queried per keystroke.
- Search source loading uses independent settlement so one failed source does not blank all results.
- Facet sections avoid presenting misleading results when filters they cannot faithfully apply are active.
- Comment author filtering honors `author:`.
- Search UI messaging no longer claims a complete public index.

## Preserved
- V84 Knowledge Engine.
- Existing search/recommendation architecture.
- Existing permissions before ranking.
- Existing routes and legacy compatibility.
- Existing mobile/desktop UI.
