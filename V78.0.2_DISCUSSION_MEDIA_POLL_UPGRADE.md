# OFFSCRPT V78.0.2 — Discussion Media + Poll Upgrade

## Fixed
- Discussion polls now render as real poll blocks on discussion detail pages and feed/discovery cards.
- Poll voting persists a per-user vote and atomically updates poll counters for root and community discussions.
- Uploaded discussion images/videos now use `mediaUrls` as the canonical media source for previews.
- The first uploaded image is promoted to `coverImage` when a cover was not explicitly supplied, preserving compatibility with older card renderers.
- Reusable `PostMediaPreview` rendering was added to home discovery, social/community feeds, search, and creator profile post surfaces.
- Community post extras now use the shared media preview and poll components.
- Compact feed cards avoid nested interactive elements around polls.
