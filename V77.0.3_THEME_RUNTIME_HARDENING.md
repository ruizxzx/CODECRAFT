# V77.0.3 — Theme + Runtime Hardening

## Changes

### New visitor theme behavior
A first-time visitor with no saved OFFSCRPT theme preference now starts in **light mode** regardless of the device `prefers-color-scheme` setting. Explicit local theme choices remain respected.

### Signed-in behavior
The existing cloud-synced account theme subscription remains unchanged. A signed-in account with no saved preference continues to resolve to the platform default (light).

### PWA manifest
The dynamically generated manifest now uses absolute origin-based `start_url` and `scope` values. This avoids browsers treating hash routes as invalid relative URLs when the manifest is served from a `blob:` URL.

## Regression protection
- No Q&A data model or routes were changed.
- No Firestore rules were changed.
- No R2 upload path was changed.
- Existing feed/discovery functionality is retained.
