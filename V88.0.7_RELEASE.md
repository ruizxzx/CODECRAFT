# OFFSCRPT V88.0.7 — R2 Signed Download Fix

## Fix
- Corrected AWS Signature Version 4 query-parameter sorting to use encoded ASCII byte ordering rather than `localeCompare`.
- Corrected presigned URL serialization so query values are RFC3986-encoded exactly once.
- Download `Content-Disposition` is now passed as a raw filename and encoded once during SigV4 canonicalization.
- Existing dedicated product R2 credential isolation is preserved.

## User impact
Purchased digital-product downloads no longer depend on a malformed `response-content-disposition` signature and should download through the signed GET URL rather than opening an R2 `SignatureDoesNotMatch` error document.
